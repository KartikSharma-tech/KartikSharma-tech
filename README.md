![Type](https://img.shields.io/badge/Type-Offline%20First-orange?style=flat-square)

A professional cricket scoring application for live, ball-by-ball match scoring with full scorecards — built with the same rigor used in production scoring apps.
Feature	Details

📴 Offline	Hive-powered persistent storage
